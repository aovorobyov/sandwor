# sandwor — дизайн-система

Тёмная тема по умолчанию, светлая — черновик (`data-theme="light"`). Брендбук, правила и живые превью — в справочнике дизайн-системы; здесь — всё, что нужно коду.

Система выгружается архивом `sandwor-design-system.zip` — его кладут в проект сайта (Next.js) целиком.

## Что в архиве

| Папка | Что внутри |
| --- | --- |
| `tokens/` | `tokens.css` — CSS-переменные тем `dark` (по умолчанию) и `light`, шрифты и классы типографики; `tokens.json` — те же токены данными |
| `fonts/` | Unbounded, Golos Text, Fira Code — variable woff2 (латиница + кириллица) и лицензии OFL |
| `logo/` | SVG логотипа: для тёмного и светлого фона и одноцветный |
| `icons/` | 138 иконок Tabler outline в SVG с `currentColor` |
| `src/` | React-компоненты (`components/*.jsx`), общий `sandwor.css`, стили по компонентам, `utils.js`, `icons.js`, `index.js` |
| `types/` | `index.d.ts` — типы пропсов с описаниями |
| `preview/` | офлайн-витрина всех компонентов: откройте `preview/index.html` |

## Подключение (Next.js, App Router)

1. Скопируйте архив в `src/sandwor/` (или любую папку проекта).
2. В `app/layout.tsx` подключите стили один раз: `import '@/sandwor/tokens/tokens.css'` и `import '@/sandwor/src/sandwor.css'`.
3. Тема: по умолчанию тёмная; для светлой поставьте `data-theme="light"` на `<html>`.
4. Импортируйте компоненты: `import { Button, CaseCard } from '@/sandwor/src'`. Интерактивные компоненты помечены `'use client'`.
5. Шрифты подключаются из `tokens.css` через `@font-face`; если используете `next/font/local`, укажите те же файлы и имена семейств.

## Правила

- Цвета, отступы и радиусы — только через переменные: `var(--surface)`, `var(--space-6)`, `var(--radius-lg)`. Сырые HEX в стилях сайта не пишем.
- Классы компонентов начинаются с `sw-`; свои стили сайта не должны их переопределять — нужен новый вариант, добавьте его в компонент.
- Новая иконка берётся из Tabler outline и добавляется в `src/icons.js`, новый токен — в `tokens.json` и `tokens.css` обеих тем.

## Компоненты

- `Logo` — Логотип sandwor: строчная надпись Unbounded 700 с трекингом −0,03em и янтарной точкой на базовой линии.
- `Icon` — Иконка из набора Tabler Icons (outline): один штрих 1.75, скруглённые концы, цвет берётся из `color` родителя.
- `Canvas` — Холст с точечной сеткой — единственная фактура системы; на нём живут схемы, узлы автоматизаций и обложки кейсов.
- `Avatar` — Квадратная плитка человека с инициалами (позже — с фото), янтарная только у основателя; `AvatarGroup` собирает команду в стопку с «+3».
- `Button` — Кнопка действия: primary (янтарь) — не больше одной на экран, для того, ради чего экран существует.
- `Badge` — Короткая неинтерактивная метка: услуга, статус работы, выделение тарифа, моно-тег или янтарный счётчик.
- `Tooltip` — Короткая текстовая подсказка к триггеру: открывается по наведению через 300 мс и сразу по фокусу с клавиатуры, закрывается по Esc, уходу курсора и потере фокуса.
- `Toast` — Короткое сообщение о том, что только что произошло, в стопке справа снизу; закрывается само через 5 секунд, пока на него не навели курсор или фокус.
- `Tabs` — Табы с подчёркиванием: переключают панели одного экрана или фильтруют список, не уводя со страницы.
- `SegmentedControl` — Переключатель из 2–4 взаимоисключающих вариантов в утопленном треке: период, вид, размер.
- `SiteHeader` — Шапка сайта: логотип слева, разделы по центру, одна primary-кнопка справа; на узком экране разделы уходят в бургер и MobileMenu.
- `MobileMenu` — Полноэкранное мобильное меню: крупные разделы, группа услуг, кнопка «Обсудить проект» внизу и контакты — открывается из бургера SiteHeader.
- `Breadcrumbs` — Хлебные крошки над заголовком страницы: путь от главной до текущей страницы, разделённый шевронами.
- `Pagination` — Постраничная навигация для длинных списков — стрелки, номера с «…» и текущая страница в янтаре; на мобильном сворачивается в «3 из 8».
- `Footer` — Подвал сайта: спокойная CTA-полоса на канве, логотип со слоганом и соцсетями, колонки ссылок и контактов, юридическая строка под линией.
- `TextField` — Поле ввода с подписью сверху и подсказкой или ошибкой снизу; в режиме `multiline` — растущая textarea со счётчиком «120 / 500».
- `Checkbox` — Флажок и радиокнопка (`Checkbox`, `Radio` из одного файла): нативный input под нарисованным квадратом 18px, подпись 15/23 и необязательное пояснение.
- `ChipGroup` — Ряд выбираемых чипов: один вариант (радиогруппа со стрелками) или несколько (кнопки-переключатели), выбранный чип — янтарная подложка и галочка.
- `Slider` — Слайдер на нативном `<input type="range">`: подпись слева, значение справа моноширинным, янтарная заполненная часть шкалы и подписи min/max или делений снизу.
- `Calculator` — Калькулятор стоимости: клиент отмечает услуги, число менеджеров и интеграции, а панель справа сразу показывает «от 49 500 ₽», срок запуска и расшифровку.
- `BriefForm` — Бриф «Обсудим ваш проект» в четыре шага — услуги, компания, задача, контакты — с проверкой на «Дальше», отправкой через промис и экраном «Заявка отправлена».
- `Modal` — Модальное окно для короткой задачи поверх страницы — бриф «Обсудим ваш проект» или подтверждение «Заявка отправлена»; на мобильном становится нижним листом.
- `ServiceCard` — Карточка направления услуг: плитка с иконкой и моно-метка услуги, заголовок, польза, состав, цена «от» и срок — целиком ссылка на страницу услуги.
- `CaseCard` — Карточка кейса: нарисованная обложка (схема, воронка или отчёт) и текст — клиент, задача, решение и 2–3 результата с одной янтарной цифрой.
- `PricingCard` — Карточка тарифа: название, что внутри, цена «от», срок, состав и кнопка «Выбрать», прижатая к низу, — выделенный тариф в ряду один.
- `TeamCard` — Карточка человека из команды: `founder` — крупно, с цитатой от первого лица и кнопкой связи; `member` — компактная строка с ролью и услугой.
- `TestimonialCard` — Отзыв клиента: глиф цитаты, слова клиента, кто сказал и где работает, по желанию — чип результата и ссылка на кейс.
- `FlowDiagram` — Фирменная иллюстрация «Схемы»: путь заявки из узлов на точечном холсте, янтарные рёбра с задержками, боковая ветка и строка показателей.
- `ProcessSteps` — Нумерованная схема этапов работы: порт с номером, связь к следующему шагу, название, одна фраза и срок.
- `PricingTable` — Таблица сравнения тарифов с липкой шапкой и выделенной колонкой; на мобильном — выбор одного тарифа и его список.
- `Stats` — Блок цифр: крупные числа Fira Code с короткой подписью, разделённые линиями `line`, одно число может быть янтарным.
- `ClientLogos` — Стена клиентов: равные ячейки 88px, разделённые линиями 1px, с серыми логотипами или нейтральными текстовыми вордмарками.
- `Accordion` — FAQ-аккордеон: вопрос в строке, ответ плавно раскрывается под ним, плюс в плитке поворачивается в крестик.
- `Article` — Страница статьи блога: крошки, бейджи услуг, заголовок, лид, автор с датой, текст 17/28 шириной 68ch и оглавление справа с 1100px.
