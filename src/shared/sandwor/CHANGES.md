# Локальные правки дизайн-системы

Папка — копия архива `sandwor-design-system.zip`. Код компонентов не правим,
кроме перечисленного ниже: это необязательные пропсы для английской версии сайта,
обратно совместимые со всеми текущими вызовами. При обновлении архива перенесите
их в саму ДС (или повторите здесь), затем запустите `node scripts/sandwor-dts.mjs`.

| Компонент   | Что добавлено                                                                                     |
| ----------- | ------------------------------------------------------------------------------------------------- |
| ServiceCard | `label` — моно-метка услуги вместо `SERVICES[service].label`; `badge` — метка справа в шапке (+ `.sw-service-card__badge` в CSS) |
| CaseCard    | `labels` — `{ task, solution, services }`: подписи строк и бейджей услуг                          |
| SiteHeader  | `menu.closeLabel`, `menu.navLabel`, `menu.label` — подписи MobileMenu для скринридера                |
| BriefForm   | `consent` — обязательный чекбокс согласия на обработку ПД на шаге «Контакты» (`values.consent`, `copy.errConsent`); `copy.fine` принимает ReactNode (ссылка на политику) |
| Calculator  | `copy.serviceLabels`, `copy.managersText`, `copy.monthsText`, `copy.managersHint`, `copy.perMonth` |

SiteHeader: уже 760px ширины шапки primary-кнопка скрыта (`.sw-header__cta`) — на телефоне
она наезжала на логотип; то же действие есть внизу MobileMenu.

Исправлено: PricingCard дописывал «₽» и к строковой цене («по запросу ₽») — по описанию
пропа строка выводится как есть, теперь знак рубля только у числа.

В типах `ButtonProps` добавлены `target` и `rel`: компонент и раньше передавал их на `<a>`,
но в `index.d.ts` их не было.

Article (`.sw-prose`): `figure > picture > img` оформляется так же, как `figure > img`, —
в статьях есть схемы с отдельной картинкой для телефона (`<source media="(max-width: 600px)">`).

BriefForm: `copy.optional` — подпись необязательного поля (раньше на EN оставалось «необязательно»);
у полей «Компания», «Имя» и «Контакт» `maxLength` 200/100/100 — те же лимиты, что проверяет сервер.

Article: проп `breadcrumbsLabel` — aria-label крошек (на EN был русский по умолчанию).

Иконки `brand-telegram`, `brand-whatsapp`, `brand-vk`, `brand-github`, `brand-youtube` заменены
официальными знаками брендов (Simple Icons, CC0; источники — брендбуки Telegram, Meta, VK, GitHub,
YouTube): заливка `currentColor`, масштаб 86% — по оптическому весу с контурными иконками Tabler.

BriefForm, экран успеха: занимает высоту формы (окно не прыгает), отметка по центру с анимацией,
блок «Что дальше» (`copy.successSteps`, `successNextTitle`) и вторая ссылка (`copy.successLink`);
проп `onStatusChange`. Исправлено: под StrictMode флаг `alive` оставался `false`, и форма
зависала в «Отправляем…».

SiteHeader + MobileMenu: бургер из трёх полосок складывается в крестик, меню открывается под
шапкой (`underHeader`), шапка остаётся над ним; разделы — Golos 17/24 вместо Unbounded 20/25;
у строк услуг плашка `badge` («скоро») вместо хвоста в названии.

Шрифты `fonts/*.woff2` урезаны `scripts/fonts/subset.py`: латиница, кириллица и типографские
знаки; начертания — Unbounded 600–700, Golos Text 400–700, Fira Code 400–600 (в `tokens.css`
диапазоны `font-weight` у `@font-face` сужены так же). 199 → 158 КБ на первой загрузке.
При обновлении ДС — прогнать скрипт на новых файлах.

Статьи (`.sw-prose`): нумерованные списки — 1, 2, 3 вместо 01, 02, 03 (`counter(sw-prose-ol)`
без `decimal-leading-zero`).

ProcessSteps и BriefForm: проп `padNumbers` (по умолчанию `true`, как в ДС). `false` — номера
этапов и шагов «Что дальше» без ведущего нуля: 1, 2, 3 вместо 01, 02, 03. Сайт передаёт `false`.

MobileMenu: прокрутку страницы блокирует на `<html>`, а не на `<body>` — у сайта на корне
`overflow-x: clip`, и `body { overflow: hidden }` превращал body в контейнер прокрутки: липкая
шапка над меню, открытым ниже первого экрана, уезжала вверх вместе с крестиком. На планшете
(≥761px) меню под шапкой — на всю ширину, без колонки 560px, направления в две колонки, лист не
длиннее экрана за вычетом шапки (`sandwor.css`).

SiteHeader: иконка-ссылка (`secondary`) — кнопка размера m (40px, иконка 20px), вровень с
бургером; пока открыто меню, она скрыта так же, как CTA (`visibility: hidden`, место остаётся).

Logo: знак векторный (из `sandworlogo.svg` / `sandworlogowide.svg`), а не живой текст с точкой.
Блок по-прежнему 1em (`size` — прежний кегль), слово 0.79em в высоту. Новый проп `studio` —
длинный знак «sandwor studio» (палочка «d» вверх, «studio» акцентом справа от неё над «wor»);
`studio="animate"` — два круга по 7 с (палочка вырастает, «studio» выезжает из-за неё, пауза
3,5 с, «studio» уезжает обратно, палочка опускается), затем знак собирается и остаётся «sandwor
studio»; наведение мыши проигрывает один круг (2,45 с); пока открыт диалог (`aria-modal`: меню,
бриф) — анимация на паузе; при `prefers-reduced-motion` — статичный финал. Компонент стал
клиентским (`'use client'`, состояние фазы). Контуры знака вынесены в `src/logoPaths.js` — их же
используют OG-картинки; файлы `logo/*.svg` перерисованы под «sandwor studio». Кегль задаётся переменной `--sw-logo-size`, контейнер может масштабировать
знак через `--sw-logo-scale` (шапка на телефоне — ×1,33, 24px). Шапка — `animate`,
подвал, MobileMenu и StatusScreen — `studio`. Стили — в `sandwor.css` (`styles/Logo.css` не
подключается).

Типы новых пропсов — в `types/index.d.ts`, помечены `[sandwor.ru]`.

Ещё добавлены файлы `src/components/*.d.ts` и `src/utils.d.ts` — их генерирует
`scripts/sandwor-dts.mjs`, руками не правим. `preview/` из архива в проект не
копируется: витрина живёт в справочнике ДС.
