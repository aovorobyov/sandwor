# Скиллы Claude Code

Скиллы проекта для Claude Code: каждая папка с `SKILL.md` — один скилл. Claude Code
находит их сам; пользовательские (`disable-model-invocation: true`) вызываются только
командой `/<имя>`, остальные модель подключает сама, когда задача подходит.

## Источник и лицензия

Скопированы из [mattpocock/skills](https://github.com/mattpocock/skills), коммит
[`5beb35b`](https://github.com/mattpocock/skills/tree/5beb35b040e3de97e54fa9e386d7e42d15c295c2)
(19.10.2026). Лицензия MIT — [LICENSE-mattpocock-skills](./LICENSE-mattpocock-skills).
Ссылка на исходную папку — в `metadata.source` каждого `SKILL.md`. Файлы
`agents/openai.yaml` (настройки для Codex) не копировали.

## Что стоит

| Скилл             | Вызов              | Что делает                                                                                                                   |
| ----------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `diagnosing-bugs` | сам или `/…`       | Отладка по циклу: быстрая воспроизводимая проверка → минимизация → 3–5 гипотез → метки в логах → фикс с регрессионным тестом |
| `grilling`        | сам или `/…`       | Интервью раундами: вопросы по дереву решений, у каждого — рекомендованный ответ                                              |
| `grill-me`        | только `/grill-me` | Короткий вход в `grilling`                                                                                                   |
| `tdd`             | сам или `/…`       | Red → green вертикальными срезами, тесты только на согласованных «швах», без тавтологий и моков своих модулей                |
| `prototype`       | сам или `/…`       | Одноразовый прототип: варианты UI на одном роуте с переключателем `?variant=` или HTML-файл для проверки логики              |
| `research`        | сам или `/…`       | Фоновый агент собирает факты из первоисточников в `.md` со ссылками                                                          |

## Правки под проект

Отличия от исходника — раздел `## sandwor.ru` в конце скилла, `metadata` во фронтматтере,
две строки в `tdd` (ниже) и форматирование prettier (кавычки в примерах, `_курсив_`).

- `tdd` — убраны ссылки на скилл `codebase-design` (не ставили); рефакторинг —
  встроенные `/code-review` и `/simplify`; добавлены Jest, `__tests__` и проверки из
  `CLAUDE.md`.
- `prototype` — варианты только на ДС, роуты в `src/app/[locale]/` с noindex, ветка
  прототипа локальная (пушим только в `sandwor_v2`), issue-трекера нет.
- `research` — заметки в локальную `docs/`, не коммитим.
- `grilling` — русские фразы-триггеры в `description`.

## Обновление

Сравнить с новой версией репозитория (`git diff 5beb35b..main -- skills/<путь>`),
перенести изменения, сохранить разделы `## sandwor.ru`, обновить коммит здесь и в
`metadata.source`, затем `npx prettier --write .claude/skills`.
