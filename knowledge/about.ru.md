# О сайте sandwor.com

sandwor.com — персональный сайт-портфолио фронтенд-разработчика. На сайте есть
блог, раздел проектов, новости (changelog), интерактивный курс и страница
контактов. Интерфейс двуязычный: русский и английский, язык переключается на
лету без перезагрузки.

## Разделы сайта

- **Главная** — краткое представление автора и три последних поста из блога.
- **Блог** — статьи, которые автоматически подтягиваются из Telegram-канала.
  Посты можно фильтровать по тегам, у каждой статьи есть прогресс-бар чтения и
  блок похожих материалов.
- **Проекты** — работы автора с описанием, технологиями, ссылками на репозиторий
  и демо.
- **Новости** — changelog сайта с версиями по semver: что и когда менялось.
- **Курс** — интерактивный учебный материал с отслеживанием прогресса по урокам.
- **Контакты** — форма обратной связи.

## Возможности

- Командная палитра по сочетанию ⌘K — быстрый поиск постов и навигация,
  переключение темы, языка и акцентного цвета.
- Тёмная и светлая темы.
- Плавные переходы между страницами (View Transitions API).
- RSS/Atom-лента, sitemap с hreflang, JSON-LD разметка, динамические OG-картинки.

## Технологии

Сайт построен на Next.js 14 (App Router) и TypeScript. Архитектура организована
по методологии Feature-Sliced Design. Локализация — через next-intl, темы —
через next-themes. Блог работает на интеграции с Telegram: посты парсятся с
публичной страницы канала и кэшируются, а webhook сбрасывает кэш при новой
публикации. Сайт задеплоен на Vercel.
